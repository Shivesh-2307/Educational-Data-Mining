# Archived treatment-classification analysis

This folder holds the earlier `Student_LLM_Unified_Pipeline_SHAP` analysis and its report. It clusters student interaction features and predicts treatment assignment (`aug` = GPT Tutor; `vanilla` = GPT Base). It does not predict academic scores, so it is not part of the current learning-outcome process.

Its saved charts and tables are retained under `outputs/legacy_treatment_classifier/`. The current project notebooks are in `notebooks/`; use those and the scripts in `Research_Analysis/` for the active analysis.

`Regression.py` is an unfinished historical template. It requires a real numeric target to run and is not used by the current pipeline.
