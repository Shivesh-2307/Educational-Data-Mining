# Student-AI Learning Outcome Research

This project studies whether students' language and interaction patterns while using GPT Base (`vanilla`) or GPT Tutor (`aug`) relate to their later math scores.

## Start here

Read the notebooks in order:

0. [Pre Processing](notebooks/01_text_features_and_data.ipynb)
1. [Text features and data](notebooks/01_text_features_and_data.ipynb)
2. [Interaction profiles and treatment](notebooks/02_interaction_profiles_and_treatment.ipynb)
3. [Learning outcomes](notebooks/03_learning_outcomes.ipynb)

Processed inputs are in `ProcessedDatasets/`, analysis scripts are in `Research_Analysis/`, and generated results are in `outputs/`.
